# Documentation

**taac** keeps trips in YAML files and turns them into a website, calendar feeds, maps and a shared ledger.

- [Getting Started](getting-started.md): a first trip, checked and opened in the browser.
- [Writing a Trip](trips.md): everything a trip file can hold, from plans and places to money, tasks and packing.
- [Sites](sites.md): putting several trips on one site, who can see them, and sharing them.
- [Command Line](cli.md): the `taac` command and what it builds.
- [Self-Hosting](self-hosting.md): running your own instance with Docker or Kubernetes, and its configuration.
- [Development](development.md): how the code fits together, and working on taac itself.
